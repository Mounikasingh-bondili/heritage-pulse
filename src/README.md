# 🏛️ HeriTej Pulse - Heritage Events Discovery Platform

## 📌 Project Overview
HeriTej Pulse is a modern web application for discovering and managing heritage events. Users can browse events, apply filters, view event details, register for free events, and administrators can manage event approvals.

**Live Demo:** [https://heritej-pulse-nu.vercel.app](https://heritej-pulse-nu.vercel.app)

---

## ✨ Features

### User Features
- 🏛️ **Events Listing** - Browse all heritage events with beautiful cards
- 🔍 **Advanced Filters** - Filter by category, city, price, language, and more
- 📱 **Fully Responsive** - Works on desktop, tablet, and mobile
- 🎫 **Event Registration** - Register for free events with validation
- 🔖 **Bookmark Events** - Save favorite events for later
- 📊 **Real-time Filtering** - Instant results without page reload
- 👁️ **Event Details** - View complete event information

### Admin Features
- 👑 **Admin Panel** - Manage all submitted events
- ✅ **Approve Events** - Approve pending events
- ❌ **Reject Events** - Reject with reason
- 🔍 **Search & Filter** - Search by title, filter by status
- 📊 **Status Management** - Track pending, approved, rejected events

## 🛠️ Tech Stack

### Frontend
- **React.js 18+** - UI framework
- **Redux Toolkit** - State management
- **React Router v6** - Navigation
- **Tailwind CSS** - Styling
- **Vite** - Build tool

### Deployment
- **Vercel** - Hosting and deployment
- **GitHub** - Version control

### Additional Libraries
- **React Icons** - Icon library
- **UUID** - Generate unique IDs
- **Axios** - HTTP requests (mock)
